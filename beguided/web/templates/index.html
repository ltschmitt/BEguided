What BEguided does

BEguided designs single-guide RNAs (sgRNAs) for CRISPR base editors. For every target base you supply, it searches the genome for nearby PAM sites, predicts which editable window (relative to the PAM) the base falls into, scores the guide, annotates bystander editing, and (optionally) runs an off-target search.

Upload a targets file (TSV / CSV / XLSX) using the field above to get started. Use the Template button to download a sample.

Input format (1-based positions)

The position column is 1-based: position 1 is the first nucleotide of the chromosome, position 2 the second, and so on. The value is the genomic coordinate of the base you want to edit.

Required columns:

  • chromosome — e.g. chr1
  • position — 1-based genomic coordinate of the target base
  • target_base — base you want to edit (A, C, G, T)
  • desired_base — base you want to have after editing (A, C, G, T)

The tool picks a preset that supports the target_base → desired_base change. If no preset in the selected group supports it, that target is skipped with a warning.

Available presets

Editing windows are position ranges, counted from the PAM-distal end of the guide, where the base editor is active. General = the full window where some editing occurs; High-activity = the narrower window where editing is most efficient.
