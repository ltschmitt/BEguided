What BEguided does

BEguided designs guide RNAs (sgRNAs) for CRISPR base editors. For every target you supply and each base editor you select, it searches for nearby PAM sites, predicts which editable window (relative to the PAM) the base falls into, scores the guide and annotates bystander editing.

Upload a targets file (TSV / CSV / XLSX) using the field above to get started. Use the Template button to download a sample.

Spreadsheet input

Provide a Spreadsheet of genomic targets you want to edit. BEguided will design guides for all targets provided and base editors selected. Target bases not present in the genome will be replaced with the target base.

The position column is 1-based: position 1 is the first nucleotide of the chromosome, position 2 the second, and so on. The value is the genomic coordinate of the base you want to edit.

Required columns:

  • chromosome — e.g. chr1
  • position — 1-based genomic coordinate of the target base
  • target_base — base you want to edit (A, C, G, T)
  • desired_base — base you want to have after editing (A, C, G, T)

The tool picks a base editor profile that supports the target_base → desired_base change. If no profile in the selected group supports it, that target is skipped with a warning.

Sequence input

Instead of a targets file you can paste one or more sequences directly. Switch the input mode at the top to Sequence, then mark the desired edit with a bracket like [A>G] (or [T>C], [C>T], [G>A]). The bracket becomes the base at that position — text after ] shifts one position later in the resulting sequence.

Example: ATAG[T>C]GAC gives a 9-nt stripped sequence ATAGTGAC where position 5 is T (from the bracket) and positions 6…9 are G, A, C. The base you want to edit goes on the left side of >.

A single sequence without a FASTA header gets the chromosome name custom; with a FASTA header (anything after > up to the first whitespace) the header is used as the chromosome name. In sequence mode the loaded reference genome and bystander annotation are not used — guides are designed directly on the provided sequence.

Available base editor profiles

Editing windows are position ranges, counted from the PAM-distal end of the guide, where the base editor is active. General = the full window where some editing occurs; High-activity = the narrower window where editing is most efficient. The full profile table lives on the Base Editors tab, where you can also upload a custom profiles spreadsheet.
